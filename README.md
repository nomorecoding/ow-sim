# 守望天梯人生模拟器

静态单页文字模拟：每季摇一次天赋，系统按 MMR 控你的胜率，你在青铜到英杰之间被推来推去；攒够成长后天赋分布上移，打进 OWCS 中国赛区，或者去黑市走捷径，或者负债、上班、退役、当主播组队。

**在线玩：https://nomorecoding.github.io/ow-sim/** （每次推 `main` 自动重新部署）

## 本地运行

```bash
npm install
npm run dev
```

## 机制速览

设计定稿见 `docs/plans/2026-09-03-ow-realism-design.md`。骨架全部用现实里已有的东西。

- **逐把滚动**：左栏对局、右栏事件；每把带真实修正词（逆风局 / 安慰奖 / 预期 / 大逆转 / 校准 / 压力 / 保级保护 / 连胜连败趋势）。速度 0.05–1s 可调，也可手动一把一把点。
- **天赋（隐藏 MMR）**：每季开局随机摇一档：木桶 / 普通 / 有点东西 / 天才 / 怪物。全局成长（赛季经验、英雄池、设备、战队训练）只改摇到高档的**概率**，不改单季胜率。25 岁后成长被年龄抵消。
- **系统控分（SR vs MMR 双轨）**：匹配按系统对你的估计找对手，校准期胜率高，识别后归于五五开；段位靠修正词慢慢漂向真实水平。结算揭示"本季真实水平"。
- **段位**：青铜 5 → 英杰 1，各 5 小段；顶尖 500 为榜单（需 ≥25 胜）。每赛季 10 把定级 → 常规 → 竞逐周。每 3 季软重置；封号换新号归零。
- **钱**：真实元级别。学生生活费、上班工资、辍学没收入还要交房租；可以负债，每季 6% 利息。负债时首页给三条路：找份正业（放弃职业梦）、去黑市接单、咬牙坚持。干干净净从负债打到单季职业收入 30 万或国际赛冠军 → 「地狱归来」。
- **职业线（2026 OWCS 中国赛区）**：
  - 入口：宗师以上被战队私信，或触及宗师 / 打满 10 季后在「职业路」页**主动报名试训**。3 场 BO3 训练赛，过了先**背调**再签。
  - 签约后天赋兜底「有点东西」+ 训练成长加成：职业选手在钻石–英杰之间浮动。
  - 6 季 = 1 年，第 2 / 4 / 6 季末打 Stage：公开预选瑞士轮 → 常规循环 → 双败季后赛 → 国际赛（Champions Clash 首尔 / 年中赛 EWC 利雅得 / 世界总决赛）。底薪 + 奖金分成。
  - 花边：队友假赛全队取消资格、宫斗、主力被挖、韩援补强、老板撤资解散、赞助商跑路。年末转会窗续约 / 被裁 / 被挖；世界杯国家队；25 岁后退役概率递增，退役转主播 / 教练 / 陪玩。
  - **黑历史**：接过的代练单、请过的代练陪玩、开过挂的赛季全部记账。签约背调、每次赛前审查都有概率翻出来 → **终身禁赛**，本存档职业线永闭。
- **主播线**：人气随段位峰值、直播、职业成绩涨，不播不打职业会掉。人气 ≥ 3 万可花 5 万**组主播队**：老板兼首发，每季付队友底薪 1.5 万、拿人气赞助、奖金双份；成绩差或负债太深会解散。
- **黑市**：代练替你打 10 把（胜率按代练段位与你的差算，上限 95%）；陪玩和你一起打（同档低 8 点，可 4 陪 1，OWL 级 388/h 顶到 90%）。
  - **开赛前可预订**，第一把就上号，定级一起打。
  - 套餐打完弹窗：续单 / **提前收官锁定段位**（剩余把数作废）/ 自己打（系统会一把把把分修正回去）。
  - 赛季末对手更硬，帮手胜率 −10 点。
  - 接代练单来钱快但进黑历史；开挂免费，吃举报与封号。**信誉**才能净修环境。黑市不在开局摆出来，连败或段位低于水平一大段时会有人私信你。
- **竞技点**：胜 +15、季末按段位发；3000 换金枪，每年限一把玉枪。
- **成就**：不加胜率。每 5 个成就 → 英雄池 +1 → 天赋分布上移。

## 云泥之隔

赛季最后 12 把进入控温窗口，掷一次骰决定是否把你按在「大段 1·99」上。经典判词对应 **白金1·99 → 差 1 分翡翠5**（其它大段门同样结构换词）。提前收官不触发。
