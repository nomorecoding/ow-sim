# 守望天梯人生模拟器

静态单页小游戏：定级 → 常规 → 竞逐，现金/信誉，陪玩代练与开挂，以及赛季末「云泥之隔」（大段 1·99 差 1 分）趣味结局。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里的本地地址。

## 分享给 QQ 群友

可行：纯前端 + `localStorage`，不需要服务器账号系统。

```bash
npm run build
```

把 `dist/` 部署到任意静态托管，把链接丢群里即可，例如：

- [Cloudflare Pages](https://pages.cloudflare.com/) / [Vercel](https://vercel.com/) / [GitHub Pages](https://pages.github.com/)
- 或内网/自己的 Nginx 指到 `dist`

每人浏览器各自存档；换设备不会同步（可后续再加导出存档）。

直达链接：`?go=play` 直接开局，`?go=market` / `shop` / `ach` / `about` 直达对应页。

## 机制速览

设计定稿见 `docs/plans/2026-09-03-ow-realism-design.md`。骨架全部用现实里已有的东西。

- **逐把滚动**：左栏对局、右栏事件；每把带真实修正词（逆风局 / 安慰奖 / 预期 / 大逆转 / 校准 / 压力 / 保级保护 / 连胜连败趋势）。速度 0.05–1s 可调，也可手动点一把打一把。
- **天赋（隐藏 MMR）**：每季开局随机摇一档：木桶 / 普通 / 有点东西 / 天才 / 怪物。全局成长（赛季经验、英雄池、设备、战队训练）只改摇到高档的**概率**，不改单季胜率——斗罗里"武魂概率可提升、先天魂力仍随机"的同款。25 岁后成长开始被年龄抵消。
- **系统控分（SR vs MMR 双轨）**：匹配按系统对你的估计找对手，校准期胜率高，识别后归于五五开；段位靴修正词慢慢漂向真实水平。结算揭示"本季真实水平"。
- **段位**：青铜 5 → 英杰 1，各 5 小段；顶尖 500 为榜单（需 ≥25 胜）。每赛季 10 把定级 → 常规 → 竞逐周。每 3 季软重置；封号换新号归零。
- **职业线（2026 OWCS 中国赛区）**：宗师 1 以上被战队私信 → 试训 3 场 BO3 → 签约（合作队 / 普通队）。6 季 = 1 年，第 2 / 4 / 6 季末打 Stage：公开预选瑞士轮 → 常规循环 → 双败季后赛 → 国际赛（Champions Clash / 年中赛 / 世界总决赛）。底薪 + 奖金；年末转会窗续约 / 被裁 / 被挖；世界杯国家队；25 岁后退役概率递增，退役转主播 / 教练 / 陪玩。
- **黑市**：代练替你打（胜率按代练段位与你的差算，上限 95%）；陪玩和你一起打（同档低 8 点，可 4 陪 1，OWL 级 388/h 顶到 90%）。都是宽组减收益、脏环境、吃举报。接代练单来钱快但本存档永不签约；开挂免费，吃举报与封号。**信誉**才能净修环境。黑市不在开局摆出来，连败或段位低于水平一大段时会有人私信你。
- **竞技点**：胜 +15、季末按段位发；3000 换金枪，每年限一把玉枪。
- **禁言红框**：骂疑似挂哥会被红框禁言若干把、扣信誉，对方不一定封。
- **成就**：不加胜率。每 5 个成就 → 英雄池 +1 → 天赋分布上移。

## 云泥之隔

赛季最后 12 把进入控温窗口，掷一次骰决定是否把你按在「大段 1·99」上。经典判词对应 **白金1·99 → 差 1 分翡翠5**（其它大段门同样结构换词）。
