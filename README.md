# 守望天梯人生模拟器

静态单页文字模拟。**一局一辈子**：16 岁第一次打排位，一行一季往下滚，直到你不想打了——或者有人私信你来试训。

**在线玩：https://nomorecoding.github.io/ow-sim/** （每次推 `main` 自动重新部署）

## 本地运行

```bash
npm install
npm run dev
```

## 分享

- **链接**：上面的 GitHub Pages 地址，丢群里即可。每人浏览器各自存档，换设备不同步。
- **结算海报**：天梯 / 职业结算页点「分享本局」，生成带二维码的海报，扫码进主页开玩；可保存图片、复制链接。
- **单文件**：`npm run build:single` 生成 `single/守望天梯人生.html`，一个文件，发群里双击就能玩，离线可用。
- 直达链接：`?go=play` 直接开局，`?go=pro` / `ach` / `about` 直达对应页。

## 机制速览

骨架用现实里已有的东西：OW2 真实修正词、X1·99 卡分、OWCS 2026 中国赛区结构。

### 天梯阶段

- **开局摇天赋**：木桶 / 普通 / 有点东西 / 天才 / 怪物，一辈子不变，决定隐藏实力涨多快、升大段顺不顺。全局成长只改下一辈子摇到高档的**概率**。极小概率会在天赋之外再摇到一个**隐藏天赋**，各自通向一个隐藏结局。
- **热情 = 寿元**：每季打天梯要花，突破大段才回。热情见底就退坑，最晚 31 岁。
- **卡分**：大段不是直接跨的。实力到了，还得那几把打得顺：顺了就上去，不顺就卡在 X1·99，差一分。卡久了会自己想办法（换英雄池、找人复盘，都是自动事件）。热情快见底时还卡着，私信里那条广告就来了——你会怎么选也是摇的，整个游戏没有任何要你点的抉择。
- **系统控分**：显示段位跟着隐藏实力慢慢走，季末一句修正词（逆风局 / 安慰奖 / 预期 / 大逆转 / 校准 / 压力）。每年软重置重新定级。
- **人生阶段**：学生 → 22 岁毕业上班（把数少）；也可能中途辍学全职（把数多，房租自己付）。
- **被发掘**：21 岁前打到宗师以上，有概率收到青训私信。试训前有背调，账号干净才好过；过了就换一条路。
- **黑市**：能把分抬上去，但都有账要还。代练留记录，天梯里可能封 30 天，进了职业被翻出来更麻烦，还连累下几辈子；开挂迟早永封，而且从那一刻起这辈子的成就不再计入。
- **事件**：一季 0–2 条，改热情 / 实力 / 现金 / 人气 / 段位显示；有人设专属彩蛋。
- **经验与等级**：每辈子结束按最高段位给经验，进职业、拿冠军再加；升级所需经验一级比一级多一点。每一级、每一个成就，都让下辈子摇到天才 / 怪物的概率高 0.1%。首页那根天赋条上，天才 / 怪物末端亮的那一截就是攒出来的加成；每辈子结算时，条会从旧概率滑到新概率，多了多少一眼能看到。成就攒到 5 / 10 / 15 … 一直到 90，陆续解锁**成就奖励**：前期多打几季、容易上分；中后期给隐藏天赋、合作队报价、FMVP 这些小概率铺路。

### 职业阶段

- 从天梯人生里被发掘进来，单开一页：年龄、天赋、现金、人气、黑历史都带着。
- 签约起一路滚完，中间不停：每年年初摇**状态档**（低迷 / 一般 / 在线 / 巅峰 / 神仙），成绩 = 队伍底子 × 0.55 + 你 × 0.45。
- 每年三个 Stage，每一级赛事一行：网吧赛 → 社区赛 → 城市赛 → OWCS 预选 → 常规赛 → 季后赛 → 国际赛（Champions Clash）→ 总决赛级（EWC / OWCS 总决赛）。杯赛是 16 强淘汰赛，打进 4 强才有下一级的名额。页面顶上有一个和段位一样会往上跳的**赛事高度**，大字是级别，小字是具体赛事和名次——「社区赛 · 大锤杯 16 强」「总决赛 · EWC 冠军」。
- 履历有保底：打过 OWCS 的人不会再回网吧赛，年初直接从预选起步；拿过赛区冠亚军，直接常规赛；拿过世界冠军，常规赛至少四强。年成绩够好还会进国家队，休赛期去打一趟 OWWC 世界杯（娱乐性质，但冠军有它自己的成就）。年薪 + 奖金分成。
- 全自动：签约、续约、转会、板凳、赛季注册审查、热搜、退役，全是事件，不用你点。每滚完一年自动存档。
- 解锁成就时头顶会掉一条横幅，多个就排队连着弹；隐藏成就和荣誉排在前面、停得更久。
- 会发生什么、怎么收场，打了才知道。

## 视觉

默认「赛场」：深蓝黑底 / 亮橙 / 粗黑体切角，转播包装的味道。不依赖网络字体，离线一样。

设置里还有两套皮：**档案**（黑曜石 + 古铜 + 宋体）、**报纸**（米白纸 + 墨字 + 红章）。链接加 `?theme=dossier|paper` 也能直接预览。默认是**赛场**。

每辈子结束是一页「讣告」：峰值段位、结局、四格档案、他们怎么说（弹幕 / 贴吧 / 队友的几句话）、新成就、成长条，再往下是按年龄排的年表和完整日志。
