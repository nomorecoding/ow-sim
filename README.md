# 守望天梯人生模拟器

静态单页文字模拟。**一局一辈子**：16 岁第一次打排位，一行一季往下滚，直到你不想打了——或者有人私信你来试训。

**在线玩：https://nomorecoding.github.io/ow-sim/** （每次推 `main` 自动重新部署）

## 本地运行

```bash
npm install
npm run dev
```

## 分享

- **链接**：上面的 GitHub Pages 地址，丢群里即可。每人浏览器各自存档，换设备不同步。
- **单文件**：`npm run build:single` 生成 `single/守望天梯人生.html`，一个文件，发群里双击就能玩，离线可用。
- 直达链接：`?go=play` 直接开局，`?go=pro` / `ach` / `about` 直达对应页。

## 机制速览

骨架用现实里已有的东西：OW2 真实修正词、段位墙、OWCS 2026 中国赛区结构。

### 天梯阶段

- **开局摇天赋**：木桶 / 普通 / 有点东西 / 天才 / 怪物，一辈子不变，决定隐藏实力涨多快、撞墙多好过。全局成长只改下一辈子摇到高档的**概率**。
- **热情 = 寿元**：每季打天梯要花，突破大段才回。热情见底就退坑，最晚 31 岁。
- **段位墙**：每个大段之间一道墙。实力顶到墙要过检定，过不去就卡在 X1·9x；卡住了会自己想办法（换英雄池、找人复盘，都是自动事件）。热情快见底时还卡着，会弹出整个游戏唯一一次抉择——私信里那条广告一直在。
- **系统控分**：显示段位跟着隐藏实力慢慢走，季末一句修正词（逆风局 / 安慰奖 / 预期 / 大逆转 / 校准 / 压力）。每年软重置重新定级。
- **人生阶段**：学生 → 22 岁毕业上班（把数少）；也可能中途辍学全职（把数多，房租自己付）。
- **被发掘**：21 岁前打到宗师以上，有概率收到青训私信。试训前有背调，账号干净才好过；过了就换一条路。
- **黑市**：能过墙，但都有账要还。代练留记录，天梯里可能封 30 天，进了职业被翻出来更麻烦，还连累下几辈子；开挂迟早永封，而且从那一刻起这辈子的成就不再计入。
- **事件**：一季 0–2 条，改热情 / 实力 / 现金 / 人气 / 段位显示；有人设专属彩蛋。
- **经验与等级**：每辈子结束按最高段位给经验，进职业、拿冠军再加；升级所需经验一级比一级多一点。每一级、每一个成就，都让下辈子摇到天才 / 怪物的概率高 0.1%——首页那根条会一点点变色。成就攒到 10 / 20 / 30 / 40 / 50 个各解锁一档**传承**（重摇天赋、出身、人脉、热爱、底子），改下辈子的开局条件。

### 职业阶段

- 从天梯人生里被发掘进来，单开一页：年龄、天赋、现金、人气、黑历史都带着。
- 一年一局：年初摇**状态档**（低迷 / 一般 / 在线 / 巅峰 / 神仙），成绩 = 队伍底子 × 0.55 + 你 × 0.45。
- 三个 Stage 逐场滚动：公开预选瑞士轮 → 常规循环 → 双败季后赛 → 国际赛（Champions Clash 首尔 / 年中赛 EWC 利雅得 / 世界总决赛）。年薪 + 奖金分成。
- 全自动：签约、续约、转会、板凳、赛季注册审查、退役，全是事件，不用你点。
- 会发生什么、怎么收场，打了才知道。
