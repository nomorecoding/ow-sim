# 守望天梯人生模拟器

静态单页文字模拟。两条线：

- **天梯**：每季摇一次天赋，系统按 MMR 控你的胜率，你在青铜到英杰之间被推来推去；攒够成长后天赋分布上移。钱不够就去黑市，或者负债、上班。
- **职业模式**：单开的一段生涯。17 岁起步，一年一局，OWCS 中国赛区三个 Stage 逐场滚动，年末转会窗自己选队。会发生什么、怎么收场，打了才知道。

**在线玩：https://nomorecoding.github.io/ow-sim/** （每次推 `main` 自动重新部署）

## 本地运行

```bash
npm install
npm run dev
```

## 机制速览

骨架全部用现实里已有的东西：OW2 真实修正词、OWCS 2026 中国赛区结构、日月 / 东东电竞式的陪玩分级。

### 天梯

- **逐把滚动**：左栏对局、右栏事件；每把带真实修正词（逆风局 / 安慰奖 / 预期 / 大逆转 / 校准 / 压力 / 保级保护 / 连胜连败趋势）。速度 0.05–1s 可调，也可手动一把一把点。
- **天赋（隐藏 MMR）**：每季开局随机摇一档：木桶 / 普通 / 有点东西 / 天才 / 怪物。全局成长（赛季经验、英雄池、设备）只改摇到高档的**概率**，不改单季胜率。25 岁后成长被年龄抵消。
- **系统控分（SR vs MMR 双轨）**：匹配按系统对你的估计找对手，校准期胜率高，识别后归于五五开；段位靠修正词慢慢漂向真实水平。结算揭示「本季真实水平」。
- **段位**：青铜 5 → 英杰 1，各 5 小段；顶尖 500 为榜单。每赛季 10 把定级 → 常规 → 竞逐周。每 3 季软重置；封号换新号归零。
- **钱**：真实元级别。学生生活费、上班工资、辍学没收入还要交房租；可以负债，每季 6% 利息。负债时给三条路：找份正业、去黑市接单、咬牙坚持。
- **黑市**：代练替你打 10 把（胜率按代练段位与你的差算）；陪玩和你一起打（同档低一点，可 4 陪 1，OWL 级 388/h）。开赛前可预订；套餐打完弹窗：续单 / 提前收官锁段位 / 自己打。赛季末帮手胜率下降。接代练单来钱快，开挂免费但吃举报。黑市不在开局摆出来，连败或段位低于水平时会有人私信你。
- **黑历史**：接过的代练单、请过的代练陪玩、开过挂的赛季全部记账，带进职业模式。
- **竞技点**：胜 +15、季末按段位发；3000 换金枪，每年限一把玉枪。
- **成就**：不加胜率。每 5 个成就 → 英雄池 +1 → 天赋分布上移。

### 职业模式

- 天梯里触及宗师，或打满 10 季解锁。天梯的现金、人气、黑历史都会带过去。
- 一年一局：年初摇**状态档**（低迷 / 一般 / 在线 / 巅峰 / 神仙，跨生涯的职业成长只改分布），成绩 = 队伍底子 × 0.55 + 你 × 0.45。
- 三个 Stage 逐场滚动：公开预选瑞士轮 → 常规循环 → 双败季后赛 → 国际赛（Champions Clash 首尔 / 年中赛 EWC 利雅得 / 世界总决赛）。年薪 + 奖金分成。
- 年末**转会窗**：续约、转会、退役，你自己点。合作战队钱多免预选，普通队从预选打。
- 随机事件里有的要你做决定。剩下的，自己去发现。
