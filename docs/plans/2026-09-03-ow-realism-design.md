# 守望天梯人生 · 机制回归现实（设计定稿）

日期：2026-09-03

## 目标

1. 数值骨架用现实里已有的东西：OW2 的 MMR / SR 双轨、真实的段位修正词、2026 OWCS 中国赛区的职业路径。玩家一看就懂，不学自创规则。
2. 拉长游戏时间靠"全局改概率、单局仍随机"（斗罗：武魂概率可提升，先天魂力仍随机），不靠硬卡胜率。

用户已确认：A 双轨 MMR；职业线靠被发现；加年龄/退役弧；不分路。

## 1. 双轨：显示段位 SR vs 隐藏天赋 MMR

- 每赛季开局摇「本季天赋」→ 隐藏 MMR（分数尺度与 SR 相同：大段 500 分）。
  - 天赋档：木桶（青铜–黄金）/ 普通（白金–翡翠）/ 有点东西（钻石–大师）/ 天才（宗师–英杰）/ 怪物（顶尖 500 区）。
  - 开局展示天赋档与颜色，不展示精确 MMR；结算时揭示"本季真实水平"。
- 匹配系统按「系统对你的估计」找对手：`est = SR·(1−conf) + MMR·conf`，`conf` 从 0 随对局数上升（前 ~30 把校准）。
- 胜率 `p = 0.5 + (MMR − est)/1200`，夹在 0.25–0.75。→ 校准期高胜率，识别后归于五五开。这就是被诟病的"控胜率"，作为剧情呈现。
- SR 靠修正词漂向 MMR（真实 OW 的做法）：
  - 差值 `gap = MMR − SR`。赢时 `逆风局`（gap>0）加成、`预期`（gap<0）缩水；输时 `安慰奖`（gap>0）少扣、`大逆转`（gap<0）多扣。加成幅度 `clamp(|gap|/2500, 0, 0.35)`。
  - `校准`：conf<0.5 时变动 ×1.6。
  - `压力`：SR ≥ 4000 少加多扣；SR ≤ 300 多加少扣。
  - `连胜/连败趋势`：≥3 连 ±。
  - `保级保护`：某小段第一次要掉 0 分以下时停在 0；再输才降段。
  - `宽组`：被陪玩带（escortLeft>0）时收益 ×0.6（现实中宽组减收益，用来惩罚代练/陪玩）。
- 全局成长只改天赋分布：
  - 成长点 G（上限 30）：赛季经验（每季 +1）、英雄池（每 5 个成就 +1）、设备（现金买，3 级）、战队训练（签约期间每 Stage +1）、年龄（25 岁后每年 −1，30 岁后每年 −2）。
  - 权重：木桶 30·(1−0.03G)，普通 40，有点东西 20·(1+0.05G)，天才 8·(1+0.09G)，怪物 2·(1+0.12G)。

## 2. 段位与收集

- 段位：青铜 5 → 英杰 1 各 5 小段，顶尖 500 是榜单（需本季 ≥25 胜且 SR 在英杰段顶）。
- 每赛季 10 把定级 → 常规 → 竞逐周。每 3 季软重置向黄金/白金回拉（定级锚点）。
- 竞技点：胜 +15，季末按段位发奖励；3000 点换金枪。玉枪每年（第 3 个 Stage 结束）可用 3000 点换一把，限一把。
- 结局图鉴：云泥、封号、退役、世界杯、冠军、地心探索、上岸。

## 3. 职业线（2026 OWCS 中国赛区）

- 时间对齐：6 个天梯赛季 = 1 年（年龄 +1）；每年 3 个 Stage，落在第 2 / 4 / 6 个赛季末。
- 被发现：本季 ≥ 宗师 1 且已打 ≥ 40 把，或进榜顶尖 500 → 事件「有人私信：来打个训练赛？」（每季一次判定）。
- 试训：下赛季开局打 3 场 BO3 训练赛（按 MMR 判定），过 → 签约。战队分合作队（Stage 1 免预选、底薪高、更难签）和普通队。
- Stage 流程：普通队打公开预选（8 队瑞士轮，前 6 进循环赛，7–8 淘汰）→ 常规赛循环 → 前 4 进双败季后赛。名次决定奖金。地区前 2 → 国际赛（Stage1 Champions Clash / Stage2 年中赛 / Stage3 世界总决赛）。
- 钱：底薪每季（普通队 250–450，合作队 600–900）、奖金按名次、直播另算。现实里底薪低。
- 转会窗：年末（第 3 个 Stage 后）按全年成绩决定续约 / 被裁 / 被更高队挖。
- 世界杯：Stage 3 年份若全年表现前列，小概率入选国家队，荣誉成就。
- 退役：年龄 ≥ 25 每年退役概率递增；被裁且 ≥ 24 岁无人接 → 退役。退役后仍可打天梯，转主播 / 教练 / 陪玩由事件决定。

## 4. 黑市 / 环境（保留，细节换真实）

- 陪玩：胜率 +，但「宽组」减收益、污染 +。代练：赚钱、连带封号风险、终身不可签约。开挂：免费、举报 + 封号。
- 举报反馈用暴雪原文：「感谢您的举报，我们已对该玩家采取处理」。
- 信誉净修环境；污染上限 100，干净赛季自净。
- 云泥之隔：赛季末控温窗口掷一次，SR 停在大段 1·99。
